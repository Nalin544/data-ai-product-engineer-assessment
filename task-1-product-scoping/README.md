# Task 1 - Product Scoping

This task focuses on designing an internal marketing performance intelligence platform.

The solution was intentionally scoped as a lightweight internal dashboard instead of a complex AI-driven platform. The goal was to prioritize usability, reporting consistency, and reduced operational dependency before introducing advanced automation features.

Key decisions:

* Internal analysts prioritized as primary users
* Daily reporting preferred over real-time analytics
* BigQuery selected conceptually as centralized storage
* Predictive AI intentionally excluded from V1

With more time, future improvements would include:

* AI-generated recommendations
* anomaly detection
* client-facing portal
* forecasting capabilities
* real-time data synchronization
